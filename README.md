# 🍽️ سامانه هوشمند رزرو غذا

## 📋 معرفی پروژه

سامانه رزرو غذا یک پلتفرم هوشمند برای مدیریت و ساماندهی رزرو غذا با هدف اصلی **کاهش هدررفت مواد غذایی** طراحی شده است. این سیستم با رویکرد ساده‌سازی فرآیند رزرو و مدیریت پیشرفته غذا، تجربه کاربری مطلوبی را برای کاربران و مدیران فراهم می‌کند.

### 🎯 برای کاربران
- **رابط کاربری ساده و روان**: طراحی minimal و کاربرپسند
- **سرعت بالا**: انجام عملیات رزرو در کوتاه‌ترین زمان
- **امنیت**: عدم امکان رزرو غذا در همان روز (پیشگیری از تصمیمات لحظه‌ای)

### ⚙️ برای مدیران
- **سیستم مدیریت پیشرفته غذا**: کنترل کامل بر روی غذاها و رزروها
- **پنل مدیریت جامع**: مشاهده آمار و گزارشات لحظه‌ای
- **نمایش رزروهای روز جاری**: دسترسی سریع به رزروهای امروز
- **مدیریت مواد غذایی**: جلوگیری از هدررفت با برنامه‌ریزی دقیق

## 🛠️ پیش‌نیازها

قبل از نصب و راه‌اندازی پروژه، مطمئن شوید که ابزارهای زیر روی سیستم شما نصب هستند:

- Python
- django
- django-extensions 

## 📦 نصب و راه‌اندازی
pip install django==6.0.2


pip install django-extensions==4.1
